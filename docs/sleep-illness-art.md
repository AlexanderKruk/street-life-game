# Sleep illness artwork (v251)

Created with the built-in image generation tool, one call per image, using the established protagonist reference and the matching quiet-waking scene. Both images are 16:9 and show the same late-thirties man with early cold symptoms. The selected asset follows the actual sleep kind: bench, including Station, or ground. They use the shared illustrated result card and are fetched only for a newly contracted Cold wake event.

Project assets:

- `public/assets/event-sleep-cold-bench.webp`
- `public/assets/event-sleep-cold-ground.webp`

Each has 480, 768 and 1024px responsive WebP variants in the same directory, recorded in `src/imageManifest.json`. Base WebP quality is 90; responsive images use the existing quality-80 method-6 pipeline. `scripts/optimize-images.py` discovers these event sources automatically. The generated PNGs are retained by the image service. No sleep probabilities, illness rules or sleep duration change.
