Реализация: `src/loadGameSession.ts` собирает один начальный снимок; каждый ключ
читается один раз за загрузку. Загрузчик принимает `SaveReader`, не пишет
сохранения, не запускает таймеры и не применяет расходы/награды. Общие ключи и
raw-кодирование — `src/saveKeys.ts`, модели процессов — `src/stateTypes.ts`.
Повреждённые JSON, неверные формы данных, сломанные эффекты и числовые поля
получают безопасные значения; корректные соседние данные сохраняются.

Проверки v327: полный `npm test` и `npm run build` прошли. Добавлен постоянный

## Правила проведения следующих этапов

- Один законченный блок за раз, с отдельной проверенной версией.
- Сохранять тексты, баланс, оформление, порядок действий, ключи сохранений и
  правила времени, если их изменение отдельно не согласовано.
- Экраны получают данные и команды; игровые модули не импортируют `App.tsx`.
- Сохранять одного владельца игровых часов и явные правила паузы.
- Сохранять отдельное поведение нижнего меню и внутренних ссылок при прокрутке.
- Не переносить весь App в один большой hook/controller под другим названием.
- Для изменённых механик запускать соответствующие проверки; для общих
  изменений — полный `npm test` и `npm run build`.
- После этапа обновлять этот список, `AGENTS.md` и при необходимости
  `GAME_DESIGN.md`. Отмечать пункт выполненным после проверки результата.
